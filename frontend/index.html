Como funciona

O CAMP Vision lê as pastas do QNAP e grava o resultado. Aí o trabalho passa para você, nesta ordem: importar as folhas para o painel, conferir (clique na folha; dá para virar, corrigir e aprovar todas de uma vez), aprovar o lote (admin) e publicar o projeto no site (admin). A lista só aparece em "Publicadas" quando o projeto é publicado.
